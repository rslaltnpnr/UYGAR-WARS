# assets

Karakter gorsellerini bu klasore koyun (PNG, seffaf arka plan onerilir,
onerilen boyut ~96x96px):

- `idle1.png`, `idle2.png` — bekleme animasyonu kareleri
- `walk1.png`, `walk2.png` — yurume animasyonu kareleri
- `think.png` — dusunme / bekleme gorseli

Bu dosyalar eksikse uygulama otomatik olarak basit bir yer tutucu
gorsel cizer ve calismaya devam eder; yani gorselleri eklemeden once
de uygulamayi test edebilirsiniz.
